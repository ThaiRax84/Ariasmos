¿Qué es el autenticador?

Es una aplicación gratuita para el teléfono que muestra un código de 6 dígitos que cambia cada 30 segundos. Ese código, además de tu contraseña, comprueba que eres tú.

Sirve cualquiera de estas: Google Authenticator, Microsoft Authenticator, Authy o 2FAS. También cualquier otra aplicación compatible con códigos TOTP estándar.

Cómo darlo de alta

  1. Instala la aplicación desde la tienda de tu teléfono (App Store o Google Play).
  2. Ábrela y elige «Agregar cuenta» (a veces es un botón «+»).
  3. Escanea este código con la aplicación; si no puedes, escribe la clave:
    {{ qr }}

    Si no puedes escanearlo, elige «Introducir clave manualmente» (o «Introducir una clave de configuración») y escribe:

    Nombre de la cuenta: {{ cuenta_sugerida }}

    Clave: {{ secreto_agrupado }}

    Los espacios son solo para leerla mejor; puedes escribirla con o sin ellos. Si la aplicación pregunta el tipo, elige «Basada en el tiempo».

  4. La aplicación mostrará un código de 6 dígitos para esta cuenta. Escríbelo abajo antes de que cambie.
