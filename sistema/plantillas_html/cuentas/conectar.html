Conectar otra computadora

Las demás computadoras no instalan el programa: entran con el navegador. Antes, cada una debe confiar en el certificado de este equipo, una sola vez.

{% if hay_certificado %}
  1. En la otra computadora (con Windows y conectada a la misma red), abre el navegador y entra a esta misma página, o descarga aquí los archivos y pásalos con una memoria USB.
  2. Descarga instalar-certificado.cmd. Ya trae dentro el certificado público de este equipo; no contiene contraseñas ni datos.
  3. En la otra computadora, haz clic derecho sobre el archivo y elige Ejecutar como administrador. Si Windows avisa que el archivo viene de internet, elige Más información y luego Ejecutar de todas formas.
  4. Cierra y vuelve a abrir el navegador y entra a {% for n in nombres %}https://{{ n }}/{% if not forloop.last %} o {% endif %}{% empty %}la dirección de este equipo{% endfor %}.
  5. El navegador quedará pendiente de aprobación: apruébalo en Equipos.

Si prefieres instalarlo a mano, descarga el certificado raíz (ariasmos-raiz.crt) y agrégalo a «Entidades de certificación raíz de confianza» del equipo.

{% else %}

Este equipo todavía no tiene un certificado raíz publicado. El instalador lo prepara al terminar; si instalaste el programa a mano, configura la ruta del certificado público en la instancia (certificado_raiz) y vuelve a esta página.
