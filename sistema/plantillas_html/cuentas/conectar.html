  1. En la otra computadora (con Windows y conectada a la misma red), abre el navegador y entra a esta misma página, o descarga aquí los archivos y pásalos con una memoria USB.
  2. Descarga instalar-certificado.cmd. Ya trae dentro el certificado público de este servidor.
  3. En la otra computadora, haz clic derecho sobre el archivo y elige Ejecutar como administrador. Si Windows avisa que el archivo viene de internet, elige Más información y luego Ejecutar de todas formas.
  4. Cierra y vuelve a abrir el navegador y entra a {% for n in nombres %}https://{{ n }}/{% if not forloop.last %} o {% endif %}{% empty %}la dirección de este equipo{% endfor %}.
  5. El navegador quedará pendiente de aprobación: apruébalo en Equipos.

Si prefieres instalarlo a mano, descarga el certificado del servidor (ariasmos-servidor.crt), comprueba que su huella coincide con la de arriba y agrégalo a «Entidades de certificación raíz de confianza» del equipo local.
